# 经纬 · 中医经络学习图谱

Human Atlas 的中文教学扩展，保留原始 BodyParts3D 人体模型。在独立目录中运行，不修改同级街景项目。

## 打开

已构建版本：在本目录执行 `npm start`，或双击 `START_MAC.command`，然后打开 http://localhost:3016/ 。需要 Node.js 22.13 或更新版本。服务仅监听本机；关闭终端或 Ctrl+C 停止。

开发：`npm ci` → `npm run dev`。重新构建：`npm run build`。

## 已实现

- 米白、暖橙与深棕中文学习工作台；362 个国标经穴与21个考纲补充条目，名称/拼音/编码搜索，部位、特定穴与考纲范围筛选。
- 集成连续0–100%结构散开滑块与2234个解剖结构目录，支持名称查看、系统筛选和独立观察。解剖目录与详情按需打开，可全部收起。
- 可旋转缩放的三维点选、双侧穴标记、局部聚焦、肌肉/骨骼/神经血管教学图层、解剖结构选中与独立观察。教学界面取消体表/透视入口，隐藏皮肤模型；原始几何数据保留，生殖系统仅在解剖目录中显式选择后展示。
- 定位文字、三步标志对照、部分肢体比例尺示意、传统功用、注意事项与资料链接。
- 四种可翻面记忆卡：定位、归经、分类、看位置认穴；键盘 Enter/空格操作。
- 候选点取穴辨认自测、答案反馈与错题安排。评分只判断所选示意点，不评估真人定位精度。
- 不会/模糊/记住了：分别安排10分钟/1天/逐步延长复习；到期与未学卡筛选、收藏。
- 最多三个穴位并排比较。
- 个人课程、穴位清单、自动保存课堂笔记、JSON 导出导入。
- 三个原创定位/归经/安全情境练习，提交后显示解析；尚非临床病例库。
- 桌面目录可拖动分隔线或用键盘调宽，也可放大阅读；筛选区可折叠，手机使用可关闭的目录抽屉。原版完整英文解剖浏览器保留于 `/?view=anatomy`。

## 内容精度与实际范围

名称目录覆盖2021国标362经穴及21个考纲补充条目。382条有定位文字，三角灸仅收录考纲名称，定位待核验，不进入答题。多点穴组单独标注，不能将383条目理解为383个体表点。印堂使用国标编码GV24+，不是GV29。

考纲筛选覆盖官方2025版大纲点名的实践技能90个、医学综合180个穴名（2026沿用）；不是整个执医考试题库。出处和计数口径见 [考纲核查](docs/exam-scope-research.md)。新增资料的主治、特定穴和解剖关联未核验处保留空缺，不生成答案。

三维标记仍只有39个初始示意穴位，其他条目显示待标定提示。种子坐标手工估计后投射到参考模型皮肤表面，**并未完成医学定位校准**。表面贴合只能修正深度，不能证明穴位位置准确。肢体比例尺端点也是模型示意。

选点连线仅连接已收录穴位，不是完整经络循行。模型是一个成人男性参考，不包含女性、个体差异、可变体位或施针深度仿真。

传统功用资料按已查看机构正文与待逐条核验区分，均待专业课程教师审校；定位标准不被当作疗效证据。来源与逐穴支持情况见 [内容来源](docs/content-sources.md)。课程笔记是个人记录，不构成专业审核标记。针刺、艾灸操作动画、完整经络路径、临床辨证病例和专业审校工作流尚未实现。

目前490/2234个网格条目有中文名称，1744个仍明确显示待核对；原始英文默认折叠。新增名称附术语来源，来源对照不等于专业审校，也不是全部3432概念的专业汉化。详见[名称来源及覆盖](docs/anatomy-terminology-sources.md)。

尚未导入考试题库，也未完成独立的执医考试题组模块。记忆卡片与三个原创情境不能冒充考试题库。已核查的候选数据存在来源授权、识别错误或答案复核缺口；详见[题库来源核查](docs/exam-bank-source-audit-2026-09-06.md)。目录与三维点数的区别、外部坐标资料限制见[定位数据核查](docs/acupoint-placement-audit-2026-09-06.md)。

## 数据保存

收藏、记忆进度和课程存在当前浏览器的 localStorage（`human-atlas-tcm:v1`）。没有账号与服务器上传。`localhost` 与 `127.0.0.1` 是不同的浏览器存储来源，日常请固定使用同一地址。导出课程文件只包含课程名称、穴位清单和笔记，不含复习成绩。清除浏览器数据会丢失未导出的记录。
