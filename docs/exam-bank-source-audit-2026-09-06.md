# 中医执业医师题库来源核查（2026-09-06）

## 结论与当前边界

尚未导入新的考试题库。当前 `CASES` 的3个情境是学习练习，不是中医执业医师资格考试完整题库。题库来源、答案质量、大纲适用性是三个不同的门槛，下载成功或开源许可证标签不代表答案已核验。

用户目标为中医执业医师资格考试，不是执业助理医师、中级职称、经典等级考试或规培结业考核。不得为扩充数量混入这些题目。保留 A1/A2 单题、B1 共用备选项、A3/A4 共用病例题组原有关系；不能把基本概念/理论分类自动当作官方题型。

## 官方试题边界

[国家中医药管理局中医师资格认证中心声明（2023-08-18）](https://www.tcmtest.org.cn/contents.jsp?channelId=9BA1FC5046F9ED4C&contentId=CE05FEB2CC41E04D)说明其未对外提供历年试题，也未授权第三方传播历年真题。因此不把网上自称“官方历年真题”的内容导入或打上官方标签。此边界不排斥具有明确授权的原创模拟题。

## 可进入后续导入流程的必要字段

- 明确的目标考试、科目、适用大纲与出版/修订年份；不将未知年份自动补为当前年。
- 原始题干、A—E选项、答案、解析、题型，以及共用题干/共用选项的组号。
- 可访问的原始来源、作者或权利人、允许当前使用方式的授权依据。
- 逐题答案/解析一致性和大纲对应核验记录；争议题隔离，不计入可练题量。
- 教师专业审阅与程序校验分别记录，不能把自动结构校验记为医学专业审校。

来源检索与筛选由项目继续承担，不以用户提供机构文件为前提。机构授权资料只是可选来源之一。不得用自动生成题替代用户明确要求的可靠考试题库。

## 第二轮：新增在线来源实查

本轮仅做研究和数据诊断，未把候选数据放进生产题库。使用发布者 GitHub API、原始下载链接及论文核查，而非仅根据搜索摘要统计。

### CMB：明确标注中医执业医师的候选子集

- 来源：[仓库中文说明](https://github.com/FreedomIntelligence/CMB/blob/main/README_zh.md)、[原始数据目录](https://github.com/FreedomIntelligence/CMB/tree/main/data)、[仓库 Apache-2.0 许可证](https://github.com/FreedomIntelligence/CMB/blob/main/LICENSE)。仓库许可可核对，不等同于逐题原出版来源和教学质量证明。
- 下载 `CMB.zip`，读取 `CMB/CMB-Exam/CMB-train/CMB-train-merge.json`，共有269359条。
- 三个字段严格匹配 `exam_type=医师考试`、`exam_class=执业医师`、`exam_subject=中医执业医师`，得到4417条，其中4252条单选、165条多选。只匹配后两个字段会得到4418条；不能忽略分类字段异常。
- 严格单选中，164条存在空缺选项，50条答案不是有效 A—E 或所指选项为空，3条完整记录包含 U+FFFD 替换字符；这些问题可能重叠，不能相加推导剔除量。
- 同时满足题干非空、A—E全部非空、单字母有效答案、完整记录无 U+FFFD 后，4085条通过基础结构检查，按原题干及选项序列化检查无完全重复。这只是候选数，不是答案审校通过数。
- 训练集没有解析、实际考试年份、A1/A2/B1/A3/A4细分或题组编号。不能把单选自动标成A1，也不能当作2026题库。
- 发布者说明测试答案在2024-02-21修正过；本轮统计仅针对训练文件，不把旧压缩包测试题与不同版本答案直接拼接。

### MLEC-QA：中医专门子集与原始题型标签

- 来源：[作者仓库](https://github.com/Judenpech/MLEC-QA)、[论文](https://aclanthology.org/2021.emnlp-main.698/)、[仓库 MIT 许可证](https://github.com/Judenpech/MLEC-QA/blob/main/LICENSE)。实际下载地址由作者 README 链接提供，无登录或付费绕过。
- 原始 `TCM_train.json` 24692条、`TCM_dev.json` 3086条、`TCM_test.json` 3087条，合计30865条；不是全库136236条都属于中医。
- 实查题型：A1型题15235条，B1型题8045条，A2型题6044条，A3/A4型题1541条，与论文表4相符。
- 基础题干、五选项、答案和乱码检查通过30837条；题干与选项作NFKC及去空白归一化后，30702个不同键，并发现1次同键不同答案冲突。因此不能声称“全量已去重且答案正确”。
- 所有三个TCM主文件均不含解析或题组编号，只有题目ID、题型、题干、选项、答案。B1与A3/A4已有标签不等于能够无损恢复原卷题组；不可按相邻记录强行组题。
- 附加资料文件另有81条，未自动与主文件叠加计算题量。
- 论文说明采集2006—2020年考试相关题和互联网练习，主文件没有逐题年份或执业/助理资格字段。中医学科匹配已确认，执业资格级别、最新大纲适用性与原始题目再发布权利仍需进一步明确。

## 实施更新：CMB 可重现导入

已用固定归档 `/tmp/atlas-cmb-research.zip`（SHA-256 `c2e4288127fa5e6c03cc3659d893b0bbb19e699f74fdadce8e7fa10ac5bfdd94`）和固定条目 `CMB/CMB-Exam/CMB-train/CMB-train-merge.json` 完成可重现导入。导入命令为 `node --experimental-strip-types scripts/import-cmb.ts /tmp/atlas-cmb-research.zip`；导入器先校验归档哈希，再通过 `unzip -p` 一次性按 UTF-8 解码 JSON，不执行归档中代码。

实际结果为：269359 条源记录；4420 条同时严格匹配 `医师考试` / `执业医师` / `中医执业医师`；其中4255条为单项选择题，114条因题干或 A—E 选项缺失/空白/非字符串被剔除，50条因答案所指选项缺失或空白被剔除，得到4091条结构合格候选。NFKC 加去空白的题干与选项键发现5条同答案重复行，保留各组第一条源记录；未发现归一化同键不同答案冲突。最终生成4086题。

前文“4417条严格匹配、4252条单选、3条 U+FFFD、4085条基础结构通过”是早期研究脚本对流式 Buffer 分块逐块转字符串时，在多字节 UTF-8 字符边界人工产生 U+FFFD 所致的错误统计。使用完整 Buffer 后一次解码并独立重算，归档的严格类别记录中没有 U+FFFD，所有上述4091条候选的答案均为有效 A—E 且指向非空选项。本更新保留早期记录并明确更正，不用为达到旧数字而添加无依据的过滤条件。

生成物为 `public/data/cmb-tcm.json` 和不含完整被拒医学内容的 `public/data/cmb-import-report.json`；每题保留原始源索引，展示文本只去除首尾空白。许可证原文见 `public/licenses/CMB-Apache-2.0.txt`，作者、链接、转换边界和非官方/未医学审核声明见 `public/CMB-ATTRIBUTION.md`。
