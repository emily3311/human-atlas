# 内容任务报告

## 交付范围

- 14 条经脉：LU、LI、ST、SP、HT、SI、BL、KI、PC、TE、GB、LR、GV、CV。
- 39 个指定经穴，含体表定位、3 步标志、逐穴传统功用与常见主治、安全提醒、特定穴分类、模型可匹配的解剖关键词和来源。
- 3 个原创且标明未审阅的学习案例，分别覆盖定位方法、分类和安全推理。
- Node 原生内容完整性测试。

## 编辑判断

2021 国标第 5 章是定位主来源，WHO 2008 标准用于国际编码与定位交叉核验。传统功用、主治摘要与特定穴分类另据中医药大学课程体系整理，逐穴保留“未审阅”标识，不从定位标准推导疗效。高风险区域与孕期相关点采用保守提示，但不提供操作方法。CV12 教学标志已按 2021 国标改为剑突尖。

## 后续教师复核项

1. 逐条确认教学改写是否保持国标原意，尤其肩胛区、椎体计数与骨度分寸描述。
2. 由课程教师确认传统功用、主治措辞及特定穴分类后再解除“未审阅”标识。
3. 当前解剖关键词已匹配实际 BodyParts3D 结构名，但仍只用于模型搜索，不表示针刺层次。
