# 内容任务报告

## 交付范围

- 14 条经脉：LU、LI、ST、SP、HT、SI、BL、KI、PC、TE、GB、LR、GV、CV。
- 39 个指定经穴，含体表定位、3 步标志、逐穴传统功用与常见主治、安全提醒、特定穴分类、模型可匹配的解剖关键词和来源。
- 3 个原创且标明未审阅的学习案例，分别覆盖定位方法、分类和安全推理。
- Node 原生内容完整性测试。

## 编辑判断

2021 国标第 5 章是定位主来源，WHO 2008 标准用于国际编码与定位交叉核验。传统功用不从定位标准推导：LU5、LU9、LI4、ST36、SP9、BL13、BL20、BL23、KI1、PC6、GB34、LR3、GV20、CV4 共 14 点已有可直接访问的大学或医院正文交叉核对；其余 25 点明确显示“待逐条来源核验”。所有传统内容仍保留教师未审阅边界。高风险区域与孕期相关点采用保守提示，但不提供操作方法。ST36 已恢复 2021 国标“犊鼻—解溪连线”表述；CV17 国标拼音确认是 Dànzhōng；CV12 教学骨度标志保留剑突尖。

## 后续教师复核项

1. 逐条确认教学改写是否保持国标原意，尤其肩胛区、椎体计数与骨度分寸描述。
2. 继续为其余 25 点补齐能直接看到逐穴正文的院校教材或医院来源；由课程教师确认措辞及特定穴分类后再解除“未审阅”标识。
3. 当前解剖关键词已匹配实际 BodyParts3D 结构名，但仍只用于模型搜索，不表示针刺层次。
