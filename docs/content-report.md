# 内容任务报告

## 交付范围

- 14 条经脉：LU、LI、ST、SP、HT、SI、BL、KI、PC、TE、GB、LR、GV、CV。
- 39 个指定经穴，含体表定位、3 步标志、传统理论边界、安全提醒、标签、解剖匹配关键词和来源。
- 3 个原创且标明未审阅的学习案例，分别覆盖定位方法、分类和安全推理。
- Node 原生内容完整性测试。

## 编辑判断

2021 国标是定位主来源，WHO 2008 标准用于国际编码与定位交叉核验。疗效未从定位标准推导；传统主治暂不扩写，统一保留教师审核标识。高风险区域与孕期相关点采用保守提示，但不提供操作方法。

## 后续教师复核项

1. 逐条确认教学改写是否保持国标原意，尤其肩胛区、椎体计数与骨度分寸描述。
2. 决定是否引入指定中医药院校教材，为每穴传统功用建立独立、可追踪来源。
3. 结合 BodyParts3D 实际结构名细化 `anatomy` 关键词。
