# 中医经络学习图谱 Implementation Plan

> **For agentic workers:** Use subagent-driven-development for the independent content task and review. The user approved the discussed design and requested implementation; continue without another design approval.

**Goal:** Build a runnable Chinese educational anatomy explorer with acupoints, meridian filtering, guided location, flip cards, quizzes, spaced review, comparison, course editing and case reasoning.

**Architecture:** Preserve BodyParts3D geometry and Three.js rendering; add a typed, source-linked acupoint dataset, independent projected surface overlays, a React study interface and local persistence. Existing anatomy viewer remains accessible. All unreviewed 3D coordinates are explicitly educational approximations.

**Tech Stack:** Existing React 19, TypeScript, Three.js, Vite, native localStorage, Node tests.

## Global Constraints

- Work only in the isolated human-atlas-tcm clone on codex/tcm-learning-atlas.
- Preserve upstream MIT and BodyParts3D CC BY 4.0 attribution.
- Chinese interface with bilingual fallback for anatomical structures not yet professionally translated.
- Initial curated set: at least 30 acupoints covering 14 meridians and major body regions. Do not claim full 362-point coverage.
- Medical text must identify exact source links and status. No invented expert approval, treatment guarantees, patient-specific recommendations or needle-depth simulations.
- All 3D overlays are reference-model teaching approximations pending professional calibration. Course notes are local and cannot confer clinical verification.
- Offline local study records; no accounts or external upload. Bad storage data must recover safely.
- Accessible keyboard flip cards, proper labels, reduced-motion support, responsive 390px and desktop layouts.

### Task 1: Source-linked learning content

Files: app/tcm/types.ts (contract), app/tcm/data.ts, docs/content-sources.md.
Create at least 30 independently paraphrased acupoint entries and 14 meridians with citations. Include Chinese name/pinyin/code, region, laterality, location description, three landmark learning steps, traditional theory summary, caution, tags and anatomy keywords. Do not invent source-backed efficacy. Verify GB/T 12346-2021 naming differences including GV29 印堂. Missing clinical material must state its status. Include a small set of original educational cases with reasoning explanations labeled unreviewed. Validate IDs, meridians and source presence with an automated integrity check. Report source scope/limitations.

### Task 2: Chinese anatomy and surface teaching interface

Files: app/tcm/TcmApp.tsx, app/tcm/tcm.css, app/tcm/placements.ts, app/tcm/overlay.ts, app/scene.tsx, app/anatomy.ts, web/main.tsx, web/index.html.
Add a desktop three-column jade/ivory visual learning studio, responsive panels, meridian/body/type/search filters, selected-point details, guides, labels, source links and comparison. Reuse atlas vertices; map each curated point to a fixed rough seed and project onto appropriate surface with raycasting (not clinical calibration). Bilateral points get mirrored instances. Overlay respects camera rotation, hides occluded back points, disappears during explode. Preserve original explorer through a link. Support skin, transparent skin, muscle, skeleton and neurovascular layer presets, camera controls and isolation.

### Task 3: Study tools and local courses

Files: app/tcm/study.ts, app/tcm/StudyPanel.tsx, app/tcm/CoursePanel.tsx, app/tcm/CasesPanel.tsx, tests/study.test.ts.
Cards support named-point location/meridian/type questions and hidden-name identification, click/Enter/Space flip, no answers leaked before flip, ratings and due-date scheduling. Quiz clicks select a point in the 3D model and report correct/incorrect with explanatory feedback; wrong answers enter review. Lists, empty filters, next navigation and scheduled reviews work independently. Persist review stats and course selections/notes safely; import/export validated JSON through user UI, no upload. Course mode has local annotations and per-note status, not invented professional review. Cases use fixed educational reasoning prompts and reveal explanations after submission.

### Task 4: Validate and deliver

Run npm run check, upstream atlas validation, npm run build, and Node tests for scheduling/corrupt storage/filter transitions. Use CUA to inspect desktop and mobile render and verify search, selection, flip, quiz, comparison, course and case interactions. Review changed code and fix important defects. Start localhost server bound to 127.0.0.1, open user-facing browser and leave it running. Document startup, scope, sources, tests and outstanding professional calibration needs in README-TCM.md.
