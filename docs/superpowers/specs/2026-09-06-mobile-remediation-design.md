# 网站检查问题修复设计

状态：用户已确认方案 1；移动布局与按需模型加载已实施并通过浏览器尺寸模拟验收，中文术语完成一批来源核对。完整医学内容及真机性能验收仍未完成。依据：`docs/site-qa-mobile-2026-09-06.md` 及用户“这些问题现在都要修复”。本轮结果见 `docs/mobile-remediation-verification-2026-09-06.md`。

## 工作拆分与方案选择

全部问题分为三个独立交付：移动端布局、模型加载体验、医学内容补全。布局能独立修复；医学数据需要可追溯来源，三维坐标还需要适配当前模型。

可选方案：

1. 推荐：保留桌面体验，按任务设计手机布局，分批补齐可核验内容。改动集中、回归范围清楚，保留原版连续散开功能。
2. 全端统一重做：桌面和手机都重构，视觉一致性更高，但会扩大回归范围；不符合本轮修复优先的目标。
3. 手机移除三维模型：成本较低，但会失去核心功能，不采用。

本设计先约定方案 1 的界面交付。医学补全作为独立内容工程，不用虚构数据替代缺失项。

## 第一部分：手机布局

### 模型与控件

- 保留 0–100% 连续散开滑块、键盘操作、逐结构选择、单独查看与中文优先显示。
- 手机上将上部操作栏、可视模型和紧凑底部控制栏分区；普通状态下控件不占用模型内部可视区域。
- 滑块提供收起/展开操作；选中结构只显示一行名称与详情入口，完整信息由可关闭面板承载。
- 增加应用内“专注模型”视图，隐藏非必要头部与学习面板，保留明确退出入口。不依赖移动 Safari 对全屏 API 的支持。
- 结构目录和详情不同时占据模型两侧；切换模块退出专注模式并关闭临时面板。

### 学习任务顺序

- 手机记忆卡、课堂、情境练习以学习内容为首屏，人体模型默认折叠，可主动展开。
- 记忆卡即使模型折叠也不能泄露未翻面答案；需要辨认人体的卡片保留展开模型入口。
- 取穴自测将简短题目放在模型邻近区域，作答结果和下一步紧随其后，不要求反复跨越长模型区域。
- 经穴图谱保留人体浏览，提供明确的“查看穴位资料”入口；未配置坐标时优先引导阅读已核验文字。
- 执医题库维持独立整页，不重复插入人体模型。
- 切换模块将阅读位置回到新任务开始处，不更改学习或考试记录。

### 目录和文字

- 解剖目录将搜索框放在顶部，筛选默认折叠；结果独立滚动，搜索和关闭入口持续可见。
- 手机抽屉充分使用可用高度，适配安全区、横屏和软键盘挤压；不得增加整页横向滚动。
- 320 像素宽时品牌保持紧凑，不挤掉业务链接或核心导航。
- 阅读正文以至少 14 像素为目标，辅助文字至少 12 像素；主要触控目标至少 44×44 像素，滑块保留宽触控区。
- 保留米白、橙色、深棕配色，不恢复绿色。保留 Emily AI 链接及原作者署名。

### 实现边界

- `app/tcm/TcmApp.tsx`：任务布局状态、模型专注入口、临时面板关闭及模块切换。
- `app/tcm/AnatomyPanel.tsx`：搜索置顶、可折叠系统筛选、独立结果区。
- 新建小型移动布局策略模块，集中定义哪些模式以内容优先、何时显示模型；用行为测试覆盖分支。
- `app/tcm/tcm.css`：分区布局、字体、触控区域和视口安全区；避免继续堆叠互相覆盖的固定定位规则。
- 保留 StudyStore 数据结构和存储键，不迁移或清空用户记录；不进行无关重构。

## 第二部分：加载体验

当前场景会并发加载全部模型块。本轮先让纯题库或折叠模型的学习模块不强制启动三维资源加载；需要模型时再启动，并明确提示加载、失败和重试状态。

已有模型的加载与隐藏生命周期需要统一管理，避免反复切换导致重复下载、WebGL 资源泄漏或回调更新已卸载组件。实现前用测试覆盖进入题库、展开模型、离开加载页、失败重试场景。低精度模型或重新压缩网格不在未经测量前直接引入，以免破坏拾取及穴位位置。

真实设备的内存、帧率、移动网络加载时间属于待实测指标，不把浏览器尺寸模拟称为真机验收。

## 第三部分：医学内容工程

- 中文：以模型结构 ID/概念 ID 对应可核验术语；确认左右、层级和分支。逐批记录来源与覆盖率，不仅替换“待校对”文字。
- 穴位：区分目录条目、穴组、左右镜像和实际三维定位数量。文字定位来源不能直接推导精确三维坐标。只有取得合法可用数据并与当前模型配准、核查后才新增标记。
- 题库：保留 CMB 4086 题与原始答案，解析独立关联稳定题目 ID；只收录有合法使用依据、能追溯论据的解析。答案冲突不自动覆盖，待核查题不得误标“已审核”。
- 来源集中保留在资料说明中，尊重用户不在每道题重复显示来源横幅的要求；同时不能将未审核的新增解析宣传为专业审核结论。
- 3 个原创情境练习继续与考试题库区分。增加题型、案例或全科覆盖须在来源核实后另列内容规格，不宣称现有单选题覆盖整个考试。
- 内容完成定义：每条新增数据都有对应对象、来源、适用范围和核查记录；没有证据的项目保持明确缺口，不以数量增加作为唯一验收标准。

## 验收

1. 320×568、375×844、390×844、430×844、768 像素宽及桌面 1280/1512 像素复查七个模块，无整页横向溢出。
2. 手机选中结构后，滑块、信息条和模型可同时清楚使用；专注视图可退出；散开后无强制右侧卡片。
3. 手机进入记忆卡、课堂、情境时首屏可见任务；翻面、目录搜索、题库长题干、取穴自测继续可用。
4. 所有新增行为先写失败测试，再实施；既有测试、类型检查、模型与交互检查、服务器检查及生产构建通过。
5. 浏览器复查焦点、滚动、错误日志；不提交真实答案或改写用户学习记录来测试。
6. 单独报告已修复项、仍缺来源的内容项以及未做的真机测试，不用“全部修复”概括未完成工作。

## 不自动执行的外部操作

不因本设计对公网部署、开放局域网监听或购买题库。手机实测所需访问方式在需要执行时另行确认；生产预览仍使用当前本机服务。
