# 可核验内容补全与知识卡设计

状态：待用户书面复核。用户已确认采用“可核验分批方案”，并要求增加穴位、解剖、执医错题和穴位作用四类知识卡。本设计不把无法证明的医学内容包装成已完成数据。

## 目标与交付顺序

本轮拆为四个可独立验收的交付，依次完成：来源明确的解剖中文名、CMB 严格同题解析、穴位坐标质量与校准工作流、知识卡扩展。每批数据都必须保留稳定对象 ID、来源、适用范围和自动核对结果。

“补齐”在本项目中的含义是：能由来源与当前模型对象精确对应的内容进入正式数据；暂时无法对应的内容有可见、可统计、可继续处理的状态。它不等于用机器翻译、比例推算或 AI 文本把空字段填满。

## 1. 解剖中文名称批次

- 以复旦大学托管的《人体解剖学名词》第二版为主要来源，只接收英文核心名称与来源英文术语精确对应的条目。
- 左右侧继续由现有严格规则添加；不扩展模糊匹配、词片拼接或通用后缀翻译。
- 排除同一英文词对应多个不同解剖概念、来源含左右侧但模型名称未区分、以及括号限定无法与模型概念 ID 核对的条目。
- 第一批目标为约 120 个术语核心、约 250–290 个模型条目；最终数量由上述排除规则计算，不能为了达到 290 放宽匹配。
- 每项保存来源条目号、PDF 页码、原英文和中文。测试直接核对模型 ID/名称、来源条目和总覆盖率。

## 2. CMB 参考解析

- 现有 4086 道 CMB 题及答案保持主数据，不替换题干、选项、答案或练习进度。
- 解析候选来自 Apache-2.0 标记的 TCMLE 中医执业医师数据。只有题干与 A–E 五个选项经 NFKC、空白和中英文标点规范化后全部一致，且两源答案一致时，才按 CMB 稳定题目 ID 关联解析。
- 当前研究得到 338 道严格同题，其中 336 道答案一致；2 道答案冲突必须隔离，不显示解析，也不自动改答案。
- 解析保存为独立文件，不改 CMB 原始导入物；每条保留 TCMLE 文件、题号、数据版本和源提交标识供审计。
- 答题卡提交后，有匹配项显示“参考解析”，否则继续显示“暂无解析”。按用户要求，题卡不重复显示数据源或“未经医学逐题复核”横幅；来源、许可、严格匹配规则、OCR/医学复核限制集中在“关于题库”。
- 不把 TCMLE 的其他题追加为 CMB 题，不对未匹配的 3750 题生成 AI 解析。

## 3. 穴位坐标质量与校准工具

- 为全部 383 个目录条目建立坐标状态：`unregistered`（未配准）、`pending-review`（待专业校准）、`calibrated`（已校准）。
- 现有 39 个模型位置标记为 `pending-review`，继续保留其来源和“教学示意”属性；其余条目为 `unregistered`。没有证据的数据不得拥有默认坐标。
- 默认三维图只显示 `calibrated` 点；用户可主动打开“显示教学示意”查看 `pending-review` 点，使用不同形状/颜色并保留页面级说明。未配准穴位只显示标准文字定位，不复用其他穴位的标记。
- 校准工具面向教师/项目维护者：从目录选择穴位和左右侧，在当前固定 BodyParts3D 表面点击产生草稿锚点，可微调、撤销、比较前后位置，填写依据与校对人，并导出 JSON 校准包。浏览器草稿只保存在独立本地键中，不修改正式数据。
- 普通界面不能把草稿直接标为 `calibrated`。正式状态只接受通过脚本校验且带审核元数据的校准包，再由代码评审纳入版本库。
- 导入校验检查穴位 ID、左右规则、有限坐标、表面距离、重复项、审核元数据和数据版本；失败记录整体拒绝，不部分覆盖。
- AcuSim 的多视角标注与 AcuAtlas 的未授权自有坐标均不直接导入。完整 362 标准穴位三维覆盖仍取决于合法坐标来源或教师逐点校准，界面必须显示真实完成数量。

## 4. 知识卡片扩展

### 穴位卡

保留现有定位、归经、分类、认穴卡和点击/Enter/空格翻面行为。定位卡只要求标准文字定位；认穴卡只在所选显示范围内有可用三维坐标时开放，不显示错误替代点。

### 解剖卡

- 以已具备中文名称的实际模型结构为卡片对象。
- 正面随机采用“中文名回忆英文/编号”或“英文名回忆中文/系统”的单一问题；背面显示中英文原名、结构 ID、系统中文名和来源状态。
- 未核对名称不生成解剖卡；同名不同结构保留各自模型 ID。

### 执医错题卡

- 由现有本机 CMB 错题记录动态生成，不复制或迁移答题记录。
- 正面显示题干和用户上次所选答案，不提前泄露正确答案；翻面显示正确答案。若存在严格匹配解析则一并显示，否则明确“暂无解析”。
- 用户后来在题库答对时，该题不再进入当前错题卡队列；不擅自清除历史答题次数。

### 穴位作用卡

- 只为 `traditional` 字段具有机构资料或已明确核对来源的穴位生成。现有“待逐条来源核验”的传统提要不能作为可评分答案。
- 正面问题为“某穴的传统功用学习要点是什么？”；背面显示简明传统功用、适用的理论学习范围和现有安全提示。
- 卡面使用“传统功用提要”，不使用“治疗保证”“疗效”或个体处方语言；不提供针刺深度、手法或自行治疗建议。

### 卡片数据与复习记录

- 新增统一只读 `KnowledgeCard` 视图模型，卡片 ID 使用命名空间：`point:<id>:<type>`、`anatomy:<mesh-id>:<direction>`、`exam:<question-id>`。
- 原有 `human-atlas-tcm:v1` 穴位复习记录保持不变。解剖、作用和错题卡使用独立的 `jingwei-knowledge-cards:v1` 间隔复习记录，解析时只接受当前可用卡 ID，防止原型污染和失效内容残留。
- 卡片页增加“穴位 / 解剖 / 执医错题 / 穴位作用”题库范围切换，显示真实可练数量；空队列说明缺少坐标、来源或错题记录的原因。

## 数据流与错误处理

解剖术语和解析通过离线导入脚本生成静态、可审计数据；应用只读取验证后的产物。解析文件加载失败时题库仍可答题并显示“解析暂不可用”，不能阻断 CMB 主库。知识卡解析失败时丢弃非法本地记录但不影响原穴位学习记录。校准草稿写入失败时保留当前内存编辑并提示用户导出，不能声称已保存。

## 自动测试与验收

1. 解剖：逐条核对英文核心、中文、来源条目、页码、真实模型 ID；未知后缀继续不翻译；报告新增和剩余数量。
2. 解析：用固定数据版本重建；断言 338 个严格同题、336 个答案一致、2 个冲突隔离；题目与选项任一变化都不能误配。
3. 坐标：383 条全部有且只有一个状态；39 个既有点为待校准；未配准点无坐标；草稿不能直接进入已校准状态；无效校准包整体拒绝。
4. 卡片：四类卡片正反面不泄露答案，来源/坐标门槛生效，错题状态实时派生，独立复习存储不改现有记录。
5. 运行完整单元测试、类型检查、生产构建、模型/交互/服务器验证，并在桌面与 390×844 手机模拟下检查筛选、翻面、解析展示、空状态和校准工具。
6. 不通过答题、评分或清空真实学习数据来验收；浏览器测试使用隔离测试记录或纯读取路径。

## 明确不宣称完成的内容

- 第一批之后仍未精确对应的解剖名称继续显示待校对和剩余计数。
- 336 条是跨数据集严格同题且答案一致的参考解析，不是对 4086 题的逐题医学审定。
- 在取得可合法使用并适配 BodyParts3D 的坐标数据，或完成教师逐点校准前，不宣称全部穴位已有准确三维坐标。
- 知识卡数量由已核对内容、可用坐标和实际错题动态决定，不写死为目录总数。
