- **重要版本质量标志**：该大学公开文本虽然封面列正式标准号，但正文规范性引用保留 `GB/T 12346-XXXX` 占位符；安眠一行原件含“连7线”排版异常，正文部分条号错显示为 `1.14` 等。不能掩盖这些问题而声称已与国家标准官方最终排印版本逐字一致。建议来源标签为“大学公开标准文本，待正式版对校”。内容编辑时“连7线”可注为原文排版误字，规范呈现“连线”，保留来源与编辑记录。
- 引言明确：国标收录 51 个奇穴条目，将“金津”“玉液”两名合为一个“金津玉液”条目；未见于所采用 WHO 穴名标准的新收录穴，只标汉字和拼音，不给英文代码。因此**安眠、牵正无代码并非遗漏，不能编造 EX-HN16 等代码**。

## 三角灸：明确的标准覆盖缺口

- GB/T 40997-2021 公开文本的 51 条正文清单没有三角灸，而 2025 执业医师综合考试大纲明确列入。标准穴库和考试穴库并非完全相同集合。
- 国内大学检索取得的页面主要是教学大纲，只证实它是教学内容，没有给出定位，因此**不能用那些页面为定位背书**。[广西中医药大学针灸学教学大纲](https://www.gxtcmu.edu.cn/zjtn/jysjs/zjtncfjfx/jxyhygl1/zjx/54xsgzgkfgz/jxdg8/content_26023)
- 找到教育机构自己的公开学习资料：[新加坡中医学院《学习资源18 针灸穴位及取穴方法》](https://www.singaporetcm.edu.sg/cn/doc/library/%E5%AD%A6%E4%B9%A0%E8%B5%84%E6%BA%9018%E9%92%88%E7%81%B8%E7%A9%B4%E4%BD%8D%E5%8F%8A%E5%8F%96%E7%A9%B4%E6%96%B9%E6%B3%95.pdf)，检索可读内容显示第 185 条三角灸，印刷页 231：下腹部，以患者两口角间长度作等边三角形边长；顶点放脐心，底边水平，下方两个底角为穴点。它是一个 **2 点组合**，需口角距离这个体表基准，不能等同固定厘米距离。
- 新加坡中医学院来源不是中国考试主管机关；该页面可用于候选定位资料，**本轮网页直接打开超时，尚未完整下载并目视复核其页码和图示**。在审核状态上应保留“候选来源、待核对”。该资料标题只写 `EX-CA` 分区，没有正式条码；不可从商业网站补造 `EX-CA03` 等为国标代码。
- 本轮刻意不从三角灸候选资料提取灸量、主治和操作内容；这些不在当前定位源核对范围。

## 可立即用于数据架构的事实

1. 21 个考试名称可对应 20 个已查到国标名称 + 1 个未列入国标的三角灸；其中金津与玉液在国标是一条两名。不要把“名称数”“国标条目数”“身体标记数”混在同一覆盖率分母。
2. 代码应该可空；内部 `id` 可以用自定义命名空间，但 UI 必须明确它不是国际/国家标准代码。
3. 对带有重合点的八邪、八风、十宣可保留 `overlapsWith` 关系，以免两套点重叠时 UI 只显示其一或错误判题。
4. 当前已查到可读资料不等于医学审校通过。大学版文本本身的占位符与排印异常应随来源记录保留，后续对官方最终排印本和教学教材复核。
