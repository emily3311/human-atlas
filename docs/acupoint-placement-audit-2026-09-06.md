# 穴位目录与三维标记的差异

现有目录383个学习条目，含362条十四经穴条目与21条其他学习范围条目。目录条目、双侧点和穴组不能混为一个计数。现有 `PLACEMENTS` 只有39个穴位的近似种子坐标；对称镜像和表面投射均不能当作新增医学定位或专业校准。

## 为什么画面显示得少

只有已配置坐标的条目才有三维标记；左右镜像、背面/侧面可见性及当前筛选进一步改变画面可见点数。没有坐标的条目仍可以在目录中查阅。现有39个坐标没有逐点专业核验，不能宣称其余344条已定位，更不能把均匀散点或两点之间插值当成穴位定位。

## 已搜索的外部数据

- [WHO标准穴名资料](https://www.who.int/publications/i/item/9290611057)提供361个经典穴位名称的比较资料。这是其版本的名称体系，不是本项目 BodyParts3D 网格的坐标文件，也不能据此直接否定或替代项目采用的新版国标条目体系。
- [AcuSim论文](https://www.nature.com/articles/s41597-025-04934-9)与[Dryad数据说明](https://datadryad.org/dataset/doi:10.5061/dryad.zs7h44jkz)提供头颈区域合成人体图像与标注，研究涉及174个三维穴点。不是已配准到本项目人体的全身穴位清单。其精度结果不能转移为本应用精度承诺。
- [HBot研究](https://arxiv.org/abs/2408.00481)提供另一种三维中医可视化方案和Gitee代码链接；现有访问未取得可核验的 BodyParts3D 专用定位文件。

没有下载AcuSim的13.04GB完整图片包，没有把其他模型的坐标复制进当前模型。外部模型即使含穴位坐标，仍需要确认许可、坐标系、体型、体位、解剖标志及模型配准，并逐点核查。完成这些环节前保持现有39个“教学示意”标记，不增加猜测点。

## 后续有效输入

需要针对当前模型审阅的定位记录（穴位编码、三维位置、体位、对应解剖标志、标准依据与审阅者），或能合法使用且携带可追溯定位数据的另一教学模型。原版解剖模型仍应保留，不以更换模型悄悄丢失拆解/部位名称功能。
